7. Observações para o TCC

  • A base é adequada para experimentos de recomendação baseada em conteúdo (audio features) e análises de similaridade entre tracks/gêneros.
  • popularity é um score do Spotify (0–100), não um feedback explícito de usuário. Não deve ser tratado como ground-truth de preferência individual.
  • Há muitos gêneros; para modelos, pode ser necessário agrupar ou filtrar conforme o recorte do problema.
  • Features como instrumentalness e speechiness são altamente enviesadas (muitos valores próximos de 0) - importante para normalização / escolha de distância.
  • Não há dados de interação usuário–item. Qualquer avaliação de recomendação precisará de estratégia alternativa (ex.: similaridade, hold-out por gênero, ou coleta própria).
